# Como mirar referencias.
- Descarga el HTML/CSS de cada URL antes de construir. No trabajar de memoria.
- Extraer valores concretos (tipografias, tamaños, colores, como está montada la interacción) y enseñamelos
- Agarra de cada una de las referencias *solo lo que te digo*: ignora el resto de su estética.
- Si son imagenes scanear la imagen y seguir lo mismo, solo extraer las cosas que se te piden y nada mas
